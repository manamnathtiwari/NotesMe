# NotesMe — Install on Windows (Chrome / Edge)

## What's in this folder
A complete Chrome/Edge browser extension. No build step needed — load it as-is.

## Step-by-step Installation (Windows)

### Chrome
1. Unzip this folder somewhere permanent (e.g. `C:\Users\YourName\NotesMe`).
   - Important: Do NOT delete this folder after loading — the browser reads from it.
2. Open Chrome and go to: `chrome://extensions`
3. Turn ON **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** (top-left).
5. Select the unzipped **NotesMe** folder (the one containing `manifest.json`).
6. Done — you'll see "NotesMe — Blue Edition" appear.

### Microsoft Edge
1. Unzip the folder to a permanent location.
2. Open Edge and go to: `edge://extensions`
3. Turn ON **Developer mode** (left sidebar).
4. Click **Load unpacked**.
5. Select the unzipped **NotesMe** folder.
6. Done.

## Using It
- Open any webpage.
- Click the blue circular button (bottom-right) to open the tools menu.
- Tools: Highlight, Draw (works with mouse and stylus/pen), Place Note, Sidebar, Toolbar, Clear.
- Your annotations save automatically and reload when you revisit the page.

## Notes
- All data is stored locally in the browser (`chrome.storage.local`). Nothing is uploaded.
- Annotations are saved per page URL.
- If you ever update the files, click the refresh/reload icon on the extension card.

## Files Included
- `manifest.json` — extension config
- `content.js` — in-page annotation engine
- `content.css` — styles (blue theme)
- `popup.html` / `popup.js` — toolbar popup
- `background.js` — background service worker
- `README.md` — full documentation
